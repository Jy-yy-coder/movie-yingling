## 摘要（评委一句话总评）

产品有清晰的选片痛点与可演示的「规则 + 向量 + LLM + 防幻觉」工程闭环，但作为「数可视」赛道作品，可视化仍偏沉浸包装；情绪宇宙 / Navigator / EChart / 探索档案等多项承诺未接线或无入口，现场若再缺 npz/密钥/海报，评委很容易判成「好看的聊天壳」。

## 一句话定位（改写版，更锋利）

影灵 CINE：用 590 部高分片的真实口碑 DNA，把「此刻心情」翻译成可解释的选片与陪看——不是又一个电影百科，而是带证据的推荐引擎。

## 文档 vs 实现落差 Top 10

1. **观众情绪宇宙**：About / README 宣称情绪温度、关键词、趋势；`sentiment.json` 字段齐全（emotions≈569/590、freq/trend≈满），详情页只展示 `temp` + 解读文案，`.emo-grid` CSS 成孤儿。  
2. **AI 导航员 Navigator**：`PLATFORM_DOCUMENTATION` 专章；组件挂在 `App.tsx`，全前端无打开入口（仅关闭时 `setNavigatorOpen(false)`）。  
3. **ECharts 图表层**：依赖与 `EChart.tsx` 存在，零业务引用——对「数可视」是硬伤信号。  
4. **情绪温度上色银河**：后端 `galaxy_rows()` 按 `temp` 算颜色；前端 `PlanetLayer` 改用地区色，文档「颜色=情绪温度」名不副实。  
5. **无剧透**：聊天/陪看有开关且后端 `SYSTEM_PROMPT_TALK_SAFE` 真生效；详情短评默认全开、无收起保护（旧 static 有、React Detail 无）——「全站无剧透」夸大。  
6. **情绪/场景 tags**：`590/590` 空；`recommend.py` 仍读 `tags.mood/scene`；详情标签区永远不渲染。  
7. **探索档案**：`Profile.tsx`（`#/profile`）有等级/徽章，导航无链；README 把 `#/explore` 写成档案，实际是应用 Tab 壳。  
8. **向量双引擎**：代码路径完整，仓库无 `movie_vectors.npz` → 语义层现场默认静默降级。  
9. **登录合并**：`register` + `device_id` 合并游客数据；`login` 不合并且不传 `device_id`——文档「注册时合并」部分真，完整账号连续性仍有缺口。  
10. **评论规模口径**：About≈11.7 万；`PLATFORM_DOCUMENTATION` 写「约 150 万」；复盘报告沿用 150 万——评委交叉提问会直接扣可信度。

## 30 秒 / 3 分钟话术

**30 秒**  
「豆瓣高分片太多，用户仍不知道今晚看哪部。影灵用 590 部片的五维口碑 DNA 和真实短评，把自然语言心情变成可解释推荐，并支持无剧透陪看。不是百科搜索，而是带证据的选片引擎；断网也能规则降级。」

**3 分钟**  
1）痛点：信息过载 + 推荐不可解释 + 剧透焦虑。  
2）数据：590 核心、DNA 五维、高赞好/差评、情绪统计；评论可举证。  
3）系统：规则候选 →（可选）向量补位 → LLM 只做清单内决策 → 编号/白名单防幻觉 → 失败离线。  
4）体验：3D 银河探索入口 + 聊天双模式 + 人格画像闭环。  
5）赛道诚实句：「可视化主打 DNA 雷达与银河映射；情绪细图与部分导航 UI 仍在接线中——核心价值在『数据约束的 AI』。」

## 评委刁钻问题与建议回答（至少 8 个）

1. **「这不就是 ChatGPT 套壳吗？」**  
   「壳是对话；核是候选检索与校验。LLM 看不到全库自由发挥，只能润色注入的事实卡片；推荐编号必须在 1…N，出现清单外片名会回落离线文案。」

2. **「数可视赛道，可视化在哪？」**  
   「主可视化是口碑五维雷达（可解释长板短板）和银河（评分/热度/地区空间映射）。情绪关键词与趋势数据已在 `sentiment.json`，图表层（ECharts）尚未接详情——这是明确短板，不是没有数据。」

3. **「无剧透真的有效吗？」**  
   「陪看走 `TALK_SAFE` prompt，默认不讲情节；开关关闭才允许基于差评观点讨论。详情页短评目前默认展开，严格剧透防护主要在对话链路——不会夸成全站级。」

4. **「标签为空还怎么按心情推？」**  
   「心情入口现走类型/关键词规则与 DNA；`tags.mood/scene` 全空是 D3 缺口，标签共鸣解释当前不会出现。我们用类型+DNA+评论引用兜底。」

5. **「150 万评论还是 11 万？」**  
   「以 About 口径为准：约 8.8 万短评 + 2.9 万长评 ≈ 11.7 万进入本产品证据链。更大 CSV 是上游资产，不应在答辩里混用。」（内部：立刻统一文档，避免被抓。）

6. **「向量模型现场挂了怎么办？」**  
   「`embed.retrieve` 失败返回空，主路径仍是规则推荐 + LLM；演示以离线角标证明韧性，不依赖 HF 下载。」

7. **「Navigator / 情绪宇宙文档写了，现场怎么没有？」**  
   「组件与样式遗留：Navigator 未挂入口；情绪宇宙数据未绑图表。答辩只演示已接线路径（Chat 推荐卡、雷达、银河），不现场翻未完成功能。」

8. **「拿掉 AI 还剩什么？」**  
   「仍剩：精选库、DNA、真实短评、筛选列表、相似片、人格测试、3D 浏览与规则推荐。AI 增益在自然语言解释与陪看；产品不是纯 LLM。」

9. **「和豆瓣推荐有何本质不同？」**  
   「豆瓣强在社区与协同；我们强在小而深的高分子集 + 可解释五维口碑 + 对话式约束生成，面向『今晚看哪部』而非全站发现。」

10. **「登录后收藏怎么丢了？」**  
    「注册会按 `device_id` 合并游客收藏/聊天/人格；纯登录接口尚未合并。演示优先走『游客→注册』路径，或预先用同一账号。」

## 亮点（务必保留在答辩里的）

1. **三层推荐 + 离线降级**：规则 / 向量 / LLM 决策分层，失败可演示「离线模式」——工程成熟度信号。  
2. **防幻觉铁律**：事实卡片注入 + 推荐编号校验 + 片名白名单——直接回应「AI 乱荐片」。  
3. **DNA 五维雷达可解释**：长板/短板话术与推荐卡迷你雷达，是少数「可视 + 可解释」合体点。  
4. **真实短评举证**：好评/差评带赞数，About「宁缺毋编」与空 tags 隐藏策略一致时可讲诚信。  
5. **人格 → 画像 → 路线 → 推荐重排**：比单次聊天更像「产品」，适合 3 分钟中段。  
6. **3D 电影银河开场记忆点**：开场 30 秒视觉锚，但务必立刻落到「帮你选片」价值句，避免被看成纯特效。
