## 一、项目定位回答

### 1. 这个平台解决了什么问题？
帮助高分电影（豆瓣8.0+）的选择困难症患者，通过 AI + 真实口碑数据找到适合自己的电影。

### 2. 用户为什么需要它？
豆瓣/猫眼等平台信息过载，用户面对海量选择无所适从。影灵通过 AI 理解用户情绪/需求，从 590 部精选高分片中精准推荐。

### 3. 和普通电影网站的区别？
- 3D 银河可视化（5000 颗星球）
- AI 推荐 + 陪看双模式
- DNA 五维口碑评价体系
- 真实短评数据（150万+评论库）
- 人格测试 → 专属推荐路线

### 4. AI 参与了什么？
- 意图识别（规则 + 关键词）→ 检索 → LLM 润色
- 多轮对话上下文记忆
- 电影陪看上下文注入
- 防幻觉三层校验

### 5. 数据参与了什么？
- 590 部核心电影完整元数据
- DNA 五维评分（LLM 分析生成）
- 情绪分析（基于评论统计）
- 向量语义索引（512维 bge-small-zh）
- FTS5 全文检索（jieba 分词 + bigram）

### 6. 数据可视化参与了什么？
**当前严重不足**：仅有 DNA 雷达图（SVG）和 3D 银河（Three.js）。银河更偏视觉体验而非数据分析图表。

### 7. 核心创新点
"规则推荐 + 向量语义 + LLM 决策"三层推荐架构 + 防幻觉校验机制。

### 8. 最大短板
**数据可视化严重不足** + **电影标签体系完全空置（590/590 全部为空）**。

### 9. 一句话介绍
> "影灵 CINE 是一个基于 590 部高分电影真实口碑数据，通过三层 AI 推荐架构（规则 + 向量语义 + LLM）和 3D 银河可视化，为用户提供智能选片与陪看讨论的电影 AI 助手平台。"

### 🔴 致命问题：标签体系 100% 空置

所有 590 部电影的 `tags.mood` 和 `tags.scene` 均为空数组。这意味着：
- 详情页的标签区域永远不显示
- 基于标签的推荐解释（"你的关键词在这部片里有回响"）永远不触发
- 人格测试关键词与电影的共鸣匹配永远为空
- 无法按情绪/场景筛选电影

**原因分析**：README 中明确标注 "tags / brief / warn / egg / 金句(citation) 为 D3 LLM 字段，当前 590 部全空"，但 warn/egg 实际已有数据，唯独 tags 确实全部为空。

## 三、AI 推荐闭环分析

### 当前推荐流程
```
用户输入 → 意图识别(正则) → 关键词/类型/地区解析
    ↓
规则推荐(recommend.py) → DNA 维度过滤 + 类型/地区匹配
    ↓ （不足时）
向量语义检索(embed.py) → bge-small-zh 编码 → 余弦相似度
    ↓ （有画像时）
画像重排(_blend_by_profile) → 0.7 意图 + 0.3 画像
    ↓
候选清单 → LLM Prompt 注入 → DeepSeek 选片决策
    ↓
防幻觉校验（编号校验 + 片名白名单）→ 输出
```

### ✅ 已实现的闭环环节
1. 用户需求 → 需求解析（parse_hint 正则提取）✅
2. 数据库检索 → 候选电影（规则 + 向量双引擎）✅
3. AI 生成解释（LLM 基于候选清单决策）✅
4. 防幻觉（编号校验 + 片名白名单 + 离线降级）✅
5. 上下文记忆（conversation 级别，最近 24 条消息）✅
6. 电影上下文注入（详情页进入陪看时）✅

### ⚠️ 存在的问题

| 问题 | 严重程度 | 说明 |
|------|---------|------|
| 标签为空导致推荐维度缺失 | 🔴 P0 | 无法按情绪/场景匹配 |
| 意图识别纯规则，覆盖有限 | 🟠 P1 | 复杂自然语言需求可能误判 |
| 无"排除已推荐"机制的完整实现 | 🟡 P2 | _history_seen_ids 存在但仅在聊天层 |
| 用户画像仅 DNA 五维，粒度粗 | 🟡 P2 | 无细粒度类型/导演/演员偏好 |
| 查询改写较简单 | 🟡 P2 | 仅拼接上一轮意图，无 LLM 改写 |

### "如果把 AI 拿掉，网站还能不能成立？"
**能**。规则推荐 + 向量检索 + 详情页 + 列表筛选 + 银河浏览 都可以离线工作。AI 主要增强的是推荐解释的自然语言生成和陪看讨论体验。

### "如果只是接一个 DeepSeek API，AI 创新是否足够？"
**不够**。核心创新不在 LLM 调用本身，而在：
1. 三层推荐架构（规则 + 向量 + LLM 决策）
2. 防幻觉机制（事实来源限制 + 编号校验 + 片名白名单）
3. 多轮上下文 + 电影上下文注入
4. 人格测试 → 五维画像 → 个性化推荐路线

但这些需要**更好地展示出来**，否则评委看到的只是一个聊天框。

# 《影灵 CINE · 电影智能推荐平台——项目复盘与优化报告》

## 一、项目概述

### 项目背景
在流媒体平台内容爆炸的时代，用户面对成千上万的电影选择时往往陷入"选择困难"。传统的推荐系统（如协同过滤）虽然有效，但缺乏对用户情绪、语境和深层需求的理解，也无法解释"为什么推荐这部电影"。

### 用户需求
- 快速找到符合当前心情/需求的电影
- 获得有依据的推荐理由，而非随机列表
- 在观影前后有交流和讨论的空间
- 发现与自己品味契合的隐藏好片

### 项目定位
**影灵 CINE** 是一个基于真实口碑数据的 AI 电影智能推荐与陪看平台。它从 590 部豆瓣 8.0+ 高分电影中，通过"规则匹配 + 语义向量 + AI 决策"三层推荐架构，为用户精准选片并给出可解释的推荐理由。

---

## 二、项目核心理念

**"让每一部电影推荐都有据可依，让每一次观影都有 AI 陪伴。"**

我们希望解决的核心问题：
1. **选择困难**：从海量电影中快速锁定适合"此刻的你"的那一部
2. **推荐黑箱**：让用户看到推荐的依据，而不是被动接受
3. **孤独观影**：AI 陪看讨论，让观影不再是独自面对屏幕

---

## 三、项目整体架构

```
真实数据层 → 智能推荐层 → AI 交互层 → 可视化层 → 用户体验层

数据层：
  · 590 部高分电影完整元数据（豆瓣 API 爬取 + 清洗）
  · 150 万+ 条真实豆瓣短评（全文索引 + 情绪分析）
  · 512 维语义向量库（bge-small-zh-v1.5 编码）
  · DNA 五维口碑评分（LLM 分析生成）

推荐层：
  · 规则引擎：关键词/类型/地区/DNA 维度匹配
  · 向量引擎：语义相似度检索（余弦相似度）
  · LLM 决策层：从候选清单中做最终选片 + 生成解释
  · 防幻觉机制：事实来源限制 + 编号校验 + 片名白名单

交互层：
  · 推荐选片模式：自然语言描述需求 → AI 推荐
  · 陪看讨论模式：无剧透/允许剧透双模式
  · 多轮对话记忆：上下文追问理解
  · 电影上下文注入：从详情页进入时 AI 自动知道讨论哪部

可视化层：
  · 3D 电影银河：5000 颗星球（Three.js + React Three Fiber）
  · DNA 五维雷达图：影片口碑分布
  · 匹配环 + 迷你雷达：推荐匹配度可视化

体验层：
  · 电影人格测试：12 题 → 五维 DNA 画像 → 专属探索路线
  · 探索档案：等级/徽章/收藏系统
  · 日/夜主题切换
```

## 四、核心功能

### 4.1 AI 智能推荐（问影灵）
用户用自然语言描述需求（如"最近压力大，想看轻松治愈的日本电影"），AI 通过三层推荐架构从 590 部高分片中筛选最匹配的作品，并给出基于真实数据的推荐理由。

**已实现**：
- 意图识别（情绪/类型/地区/片长约束）
- 规则 + 向量双引擎检索
- LLM 选片决策 + 理由生成
- 推荐解释卡（ExplainCard）：五维契合度对比
- 防幻觉三层校验

### 4.2 AI 陪看讨论
从电影详情页进入，AI 自动知道讨论哪部电影。支持无剧透模式（看前导览）和允许剧透模式（深度讨论）。

**已实现**：
- 电影上下文自动注入
- 无剧透/剧透双模式
- 引导话题 chip
- 真实评论引用

### 4.3 3D 电影银河
5000 颗电影星球组成的 3D 地球仪。核心 590 部按真实国家坐标钉在地表，4410 部库外精选漂浮在太空。星球大小反映评分+热度，亮度反映评价人数，颜色反映情绪温度。

### 4.4 电影人格测试
12 道精心设计的观影情境题，从情感共鸣/感官刺激/叙事解析/哲思意义四个维度评估用户的观影偏好，生成五维 DNA 画像（剧情/演技/情感/视听/节奏），并据此生成四段式个性化探索路线。

### 4.5 电影详情页
海报 + 完整元数据 + DNA 雷达图 + 影灵 AI 解读 + 真实好评/差评各 3 条 + 差评预警 + 冷知识 + 相似电影 + AI 陪看入口。

## 五、AI 应用创新

### 5.1 AI 如何理解用户
通过正则意图识别 + 关键词提取，解析用户自然语言中的情绪（催泪/燃/烧脑）、类型（科幻/爱情）、地区（日本/华语）、片长等约束条件。

### 5.2 AI 如何调用电影数据
1. 规则引擎基于 DNA 维度/类型/地区快速筛选候选
2. 向量语义检索（bge-small-zh-v1.5）补位语义匹配
3. 候选清单（含 DNA、简介、好评、差评预警）注入 LLM Prompt

### 5.3 AI 如何完成推荐
LLM 作为"决策者"从候选清单中选择 2-4 部最匹配的作品，要求：
- 只能推荐清单中的电影（不允许库外片）
- 必须说明取舍理由
- 必须基于清单中的真实数据

### 5.4 AI 如何解释推荐
每部推荐电影附带 ExplainCard：
- 五维契合度对比条（用户画像 vs 影片 DNA）
- 结构化推荐理由（模板生成，只引用真实数据）

### 5.5 AI 如何持续对话
- 会话级记忆（最近 24 条消息）
- 追问检测（代词引用、省略式追问）
- 查询改写（拼接上一轮意图）
- 电影上下文持久化

### 5.6 防幻觉机制（核心创新）
1. **事实来源限制**：LLM 只改表述，不改事实
2. **推荐编号校验**：推荐的编号必须在候选范围内
3. **片名白名单**：正文中不允许出现候选清单之外的片名
4. **离线降级**：LLM 全部失败时自动降级为规则推荐文案

## 六、数据体系

### 6.1 数据来源
- 电影基础数据：豆瓣电影 API（爬虫采集 + 清洗）
- 短评数据：豆瓣短评（约 150 万条）
- DNA 评分：LLM 分析生成（剧情/演技/情感/视听/节奏 五维）
- 情绪分析：基于评论文本统计（情绪温度/高频情绪词/好评率趋势）

### 6.2 数据规模
| 数据类型 | 数量 |
|---------|------|
| 核心电影 | 590 部 |
| 库外电影 | 23 万部（精选 4410 部入银河）|
| 豆瓣短评 | ~150 万条 |
| 向量维度 | 512 维（bge-small-zh-v1.5）|
| FTS 索引 | 全文分词索引（jieba + bigram）|

### 6.3 数据字段
每部核心电影包含：movie_id、title、year、genres、countries、languages、director、writer、actors、runtime_min、rating、rating_count、summary、brief、poster、DNA 五维、quotes（好评/差评）、sentiment（情绪分析）、tags（当前为空）、warn（差评预警）、egg（冷知识）。

### 6.4 标签体系
**当前未实现**：tags.mood（情绪标签）和 tags.scene（场景标签）字段存在但全部为空数组。这是当前最大的数据缺口。

## 九、项目创新点

### 创新 1：三层推荐架构
不是简单的 LLM 调用，而是"规则快速匹配 → 向量语义补位 → LLM 决策"的分层架构，兼顾速度、准确性和可解释性。

### 创新 2：防幻觉工程化方案
通过事实来源限制、推荐编号校验、片名白名单三层防护，确保 AI 推荐的所有电影都真实存在于数据库中。

### 创新 3：电影人格测试系统
12 道情境题 → 四维心理评估 → 五维 DNA 画像 → 四段式探索路线，形成完整的用户画像 → 个性化推荐链路。

### 创新 4：3D 电影银河地球仪
将 590 部电影按真实国家坐标钉在 3D 地球表面，用大小/亮度/颜色映射评分/热度/情绪，创造独特的电影探索体验。

### 创新 5：AI 陪看讨论模式
从无剧透导览到深度讨论，AI 始终基于真实评论数据，不编造情节，不剧透关键转折。

## 十五、最终总结

影灵 CINE 是一个具有**真实数据基础**、**工程化 AI 架构**和**独特视觉体验**的电影智能推荐平台。项目的技术深度（三层推荐 + 防幻觉 + 向量语义）和数据规模（590 部核心 + 150 万评论）在同类项目中具有竞争力。

然而，作为"数可视 AI 应用赛道"的参赛作品，当前项目在**数据可视化**方面存在明显短板——仅有 DNA 雷达图和 3D 银河，缺少能够帮助用户理解电影数据分布、趋势和关系的分析性图表。同时，**标签体系的完全空置**也影响了数据驱动推荐的完整性。

**建议优先补强**：
1. 增加 3-5 种数据统计图表（类型分布、评分分布、情绪词云等）
2. 补全 590 部电影的情绪/场景标签
3. 让 AI 的工作过程在界面上可见可感知

完成以上三项优化后，预计综合评分可提升至 **78-82 分**，具备较强的赛道竞争力。
