## 2. movies_core.json 完整 Schema（定稿基准）

每部电影一个对象。**HTTP 级的字段命名与类型以本节为准，未经双方确认不改名**。

```jsonc
{
  "movie_id": "1291546",                 // 主键（豆瓣 id）
  "title": "霸王别姬",
  "year": 1993,                          // int
  "genres": ["剧情", "爱情", "同性"],
  "countries": ["中国大陆", "中国香港"],
  "languages": ["汉语普通话"],
  "first_lang": "汉语普通话",             // languages[0]，供语言筛选
  "region": "华语",                      // 任务清单四区：华语/欧美/日本/韩国
  "director": ["陈凯歌"],
  "writer": ["芦苇", "李碧华"],
  "actors": ["张国荣", "张丰毅", "巩俐", "…最多10位"],
  "runtime_min": 171,                    // int 分钟（runtime 首个数字）
  "rating": 9.6,                         // 豆瓣评分 float
  "rating_count": 2441308,               // int
  "summary": "段小楼与程蝶衣…（movies.csv 原文）",
  "brief": "一段戏梦人生…（≤60字精炼简介，D3 由 LLM 基于 summary 改写）",
  "poster_thumb": "posters_thumb/1291546.webp",
  "poster_full": "posters/1291546.jpg",

  // —— 五维口碑 DNA（D1 规则产出）——
  "dna": {
    "剧情": 9.1, "演技": 9.6, "情感": 9.4, "视听": 8.8, "节奏娱乐": 7.9,
    "_n":    {"剧情": 83, "演技": 121, "情感": 96, "视听": 54, "节奏娱乐": 61},
    "_conf": "high"                      // high|mid|low：命中证据条数分档（见 §4.3）
  },

  // —— 偏好标签（D3 LLM 打标，13 选≤5）——
  "tags": {
    "mood":  ["😭 催泪感人", "🎞 细品剧情"],
    "scene": ["🌙 一个人深夜"],
    "_evidence": {"😭 催泪感人": ["cid1","cid2","cid3"], "…": []}  // 每标签≥3 条证据评论 id
  },

  // —— 摘录区（规则候选 + D3 终选）——
  "quotes": {
    "citation": {"text": "说好的一辈子…", "rid": "3608481", "useful": 25905,
                 "byline": "豆瓣影迷"},            // D3 从候选 5 句中选 1，程序校验原文包含
    "up1":  {"cid": "24303417", "text": "陈凯歌可以靠它吃两辈子…", "votes": 41810,
             "star": 5, "author": "momo"},        // 好评类 votes 第一（规则过滤后）
    "dn1":  {"cid": "1167719764", "text": "少年戏份大致还行…", "votes": 335,
             "star": 2, "author": "东遇西"}       // 差评类 votes 第一（规则过滤后）
  },

  // —— 避雷（D3 聚合差评共识）——
  "warn": {
    "text": "近三个小时情绪浓度极高，看完需要平复时间",   // ≤30 字一句话
    "points": ["时长近 3 小时情绪沉重", "京剧背景对年轻观众有门槛"],
    "_evidence": ["cid1","cid2","cid3","cid4"]            // 每条 point ≥3 条证据
  },

  // —— 冷知识（D3 从本片长评挖掘，可空）——
  "egg": {"text": "张国荣提前半年苦练京剧身段…", "rid": "1380398"} | null,

  // —— 展示/调试统计 ——
  "stats": {"comments_total": 150, "reviews_total": 50, "votes_sum": 264465,
            "useful_sum": 72749},
  "source_channel": "normal",            // normal | fallback（4 部分类 403 兜底片）
  "similar_top": ["1307914", "1292213", "…共8个id"],   // D1 相似片离线结果
  "build_version": "core-2026-08-04"
}
```

字段覆盖率承诺（验收线）：核心字段（dna/oster/quotes/up1/dn1）**100% 有值*；tags/warn 覆盖率 ≥98%；egg 允许 null（预计 30-40% 影片没有，宁缺毋编）；brief 100% 有值。
> *个例：若某片差评池天然过薄（如姊姊妹妹站起来仅 5 条短评），dn1 允许为空并在 build report 列名。

## 3. D0 加载与清洗层

输入三表，产出内存标准库（pandas DataFrame），规则如下：

1. **剔除 9 条空壳短评**（content=""，核实为作者删正文残留）。
2. **45 条空 author**：保留行，author 展示名改为 "豆瓣用户"。
3. **长评 930 条空 star**：保留行但**不参与**星级加权类计算（DNA、按星级归类）；仍参与文本类加工（金句/egg 候选）。
4. **votes/useful/replies 数值化**为 int；长评 publish_time 尾部"已编辑"等杂串截断到第 19 位。
5. **4 部兜底通道电影**（35267208 流浪地球2 / 2208890 姊姊妹妹站起来 / 26709258 罗小黑战记 / 26354572 欢乐好声音）打 `source_channel=fallback`：其短评 votes 权重封顶（log 后再 cap），简报里常显提醒。
6. 输出 `data/enriched/_clean_stats.txt`（剔除/标记明细，留痕）。

## 4. D1 规则加工（无需 LLM key，定下即开工）

### 4.1 摘录候选（up1 / dn1 / citation 候选）

- **up1**：本片 `好评` 类中按 votes 降序，过滤条件：content 非空、30 ≤ 字数 ≤ 180、无明显违规/广告/链接、不含手机号/QQ 号；取 top1。
- **dn1**：本片 `差评` 类同规则取 top1。差评样本不足时退而取 `一般` 类中 3 星且 votes 最高且有实质批评内容的；仍无 → 允许 null（build report 列名）。
- **citation 候选池**：本片长评按 useful 取 top5 → 每篇抽取"首句+含引号/感叹的最强句"共 ~5 句作为候选（程序切句，保证是原文子串），D3 由 LLM 从候选中选择 1 句（**只能选，不能写**）。
  - 程序防幻觉校验：`candidate ∈ movie_reviews.content` 子串断言，不通过判错重跑。

### 4.2 五维口碑 DNA（方案甲 · 规则基线）

**种子词库草案**（用户重点审核对象，§7 附完整版，此处示例）：

| 维度 | 种子词（示例，完整版见 §7） |
|---|---|
| 剧情 | 剧情/故事/情节/叙事/剧本/结构/结局/反转/伏笔/铺垫/逻辑/主线/主题 |
| 演技 | 演技/表演/演得/演员/飙戏/眼神戏/台词功底/诠释/张力/入戏/教科书 |
| 情感 | 感人/催泪/泪目/哭了/感动/治愈/破防/共鸣/心疼/动容/眼眶/温情 |
| 视听 | 画面/摄影/配乐/音乐/音效/构图/色彩/镜头/长镜头/美术/特效/光影/剪辑 |
| 节奏娱乐 | 节奏/紧凑/拖沓/燃/爽/笑点/名场面/高潮/一口气/慢热/尿点/娱乐性 |

**计算流程**（每部电影独立）：

1. 召回：本片全部短评+长评中，`content` 包含某维任一种子词的评论 → 该维证据池（一条评论可同时进入多维度池）。
2. 打分：评论 star→{1:2, 2:4, 3:6, 4:8, 5:10}；weight = 1 + ln(1+votes)（长评用 useful，且权重系数 ×1.5）。空 star 行不参与。
3. dim_raw = Σ(w·x)/Σw（该维命中评论的简单加权均值）。
4. **贝叶斯平滑**：`dim = (n·raw + m·prior)/(n+m)`，伪数 m=20，prior=全库该维均值（防小样本畸变，冷门片回到均值附近）。
5. 置信档：命中条数 n≥20 → high；8–19 → mid；<8 → low（前端可加"*样本较少"角标）。

**性能**：88k 短评+29k 长评整表向量化正则扫描（pandas `str.contains` 按种子词合并大 pattern，每维一次全表扫），全库 5 维估计 **1–3 分钟**跑完；如超预估再分块/编译优化，不向 LLM 让步。

**验收**：①覆盖率：590 部中 _conf=low 的维度占比 ≤15%；②合理性抽测：霸王别姬（演技 top）、变形金刚类（视听 top）、怦然心动（情感 top）等 10 部常识对照；③DNA 总均值与豆瓣评分 Spearman ≥ 0.4（报告里出数）。

### 4.3 相似片矩阵

`sim(A,B) = 0.5·(1−‖dna_A−dna_B‖₂/max) + 0.3·Jaccard(tags) + 0.2·Jaccard(genres)`
tags 未产出的 D1 阶段用 genres 单独跑（权重 0.65/0.35），D3 后用标签重跑一次。每部存 top8 至 `similar_top`，同时全量落 `similarity.json`。

### 4.4 短评全文索引 comments_fts.db

- SQLite FTS5 建表 `(cid UNINDEXED, movie_id, category, star, votes, body)`；
- **分词**：优先 `import jieba`（分词后以空格分隔存入 FTS），环境缺 jieba 时**回退双字 bigram**（"霸王别姬"→"霸王 王别 别姬"，免依赖保底）。开工第一步先探测 jieba 是否可用，不可用我会提示你 `pip install jieba`（唯一可能的新增依赖）。
- 验收：抽查 20 个词（如"陀螺"、"紫霞"、" prostitución野"边界词）能命中预期电影。

### 4.5 海报缩略图

- Pillow 生成 340px 宽 webp（约 30-50KB）。若环境缺 Pillow 我会提示安装，或回退直接复制 jpg（不推荐）。
- 校验：抽样 10 张可正常打开、大小 <80KB。

## 5. D2 样张审稿（用户关卡）

随机抽 **10 部**（含：华语/欧美/日/韩 各≥1、2020s 新片≥3、兜底电影 1 部、冷门片≥1），为每部输出一份 markdown 样张，形如：

```
===== 样张 #3 《流浪地球2》 (fallback通道) =====
DNA: 剧情7.9(n=44,high) 演技7.6(n=31,mid) 情感8.2(n=52,high) 视听9.4(n=118,high) 节奏娱乐8.4(n=77,high)
up1 [48891票·5★·电子梦]: 不必对比什么 作为里程碑他已经无敌
dn1 [1204票·2★·xxx]: ……
citation 候选5句: ①… ②… ③… ④… ⑤…
warn 草稿(规则词频): "时长过长"(12次) "信息密度过大"(9次) …
相似片 top8: 星际穿越(0.88) 星际穿越 … 
```

**你审核三件事**：①DNA 是否符合直觉（不附就调种子词/权重）；②摘录选条是否有问题文本（改过滤规则）；③样张格式/字段还缺什么（补 schema）。签字后进入 D3。

## 6. D3 LLM 加工（待 key，预计总成本 <¥100）

通用契约：**每步只喂该片自家数据**（top 评论截断集 + 候选清单），输出强制 JSON；**证据 id 必填**，程序回填校验；断点按电影粒度存 `build_task_llm.csv`。

| 任务 | 输入 | 输出 | 程序校验 |
|---|---|---|---|
| tags | 标题+类型+20 条代表评论（好/中/差+长评段） | mood≤3 + scene≤2（13 集内）+ 每条 ≥3 证据 cid | 标签∈13 集；证据 cid 存在 |
| citation | §4.1 的 5 句候选 | 选序号 0-4 | 必是候选原文子串 |
| warn | 差评池（ votes 加权 top30 差评 + 3星评论采样） | ≤30字一句话 + 最多3个要点 + 每要点≥3 证据 cid | 证据存在且差评占比过半 |
| egg | 本片长评全文片段池（含"片场/原型/拍摄/导演/背后"命中段） | 一句冷知识+rid；挖不到 → null | text 近似子串于 rid 正文（相似度阈值 0.85） |
| brief | summary 原文 | ≤60 字 | 长度+无新增专名（粗查） |
| DNA 校准（抽 30 部） | 同 DNA 召回样本 | 5 维分 | 与 D1 分数 Spearman≥0.6，否则报警修规则重跑 |

成本：约 590 部 × 4–5 次调用 × ~6k tokens ≈ 1,400–1,800 万 input tokens；DeepSeek 价档约 ¥30–80。先 10 片试跑给你看效果再全量。

## 9. 验收标准汇总（D4 build report 必须全绿）

1. movies_core.json 590 对象、主键无重复；quotes.up1 非空 590/590；dna 五维覆盖 590/590（conf=low ≤15%）。
2. citation 校验通过 100%（原文子串断言）；tags∈13 集 100%；warn 证据 ≥3/条目 100%；egg 子串校验 100%（null 不计）。
3. 与基线对账：DNA 总均值-豆瓣分 Spearman ≥0.4；LLM 校准轮 Spearman ≥0.6。
4. comments_fts.db 抽查 20 词全部命中；posters_thumb 590 张齐全（失败重下）。
5. 报告输出全部缺口电影名单（movie_id+缺什么+原因），由用户确认接受。
