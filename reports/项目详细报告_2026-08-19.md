# 影灵 CINE · 沉浸式 AI 电影探索空间 —— 项目详细报告

> 版本：v2.0 ｜ 日期：2026-08-19 ｜ 运行端口：8010
> 定位：把「AI 电影推荐工具」升级为「沉浸式 AI 电影探索空间」——以 3D 银河宇宙为入口，融合人格画像、AI 选片、AI 陪看与口碑数据解读。

---

## 一、项目总览

影灵 CINE 是一个以 **590 部高分电影** 为核心的沉浸式推荐与探索平台。用户进入后看到的不是传统的列表/表格，而是一个由真实电影构成的 **3D 银河**：每部电影是一颗星球，按地区分色、按评分定亮度，可拖动旋转、滚轮缩放、点击「镜头推进」进入电影空间。

产品主线围绕一句话：**「想看点什么？」** —— 用户描述心情或需求，影灵（AI 选片顾问）结合影片口碑 DNA、语义向量检索与对话上下文，从高分片库里挑片、讲理由、附真实观众评论，并支持持续追问与换片。

### 技术形态
- **后端**：Python + FastAPI + SQLite，单服务进程，静态托管前端构建产物。
- **前端**：React 19 + TypeScript + Vite + Three.js（银河场景）+ Framer Motion（过渡动画）。
- **AI**：外部 LLM（兼容 OpenAI 接口）做推荐润色/陪看问答；本地向量（512 维）做语义检索；FTS5 做影评全文检索。
- **数据**：590 部核心影片 + 88160 条真实短评 + 5 维口碑 DNA + 语义向量。

## 三、后端架构（`cine/`）

### 3.1 模块职责
| 模块 | 职责 |
|---|---|
| `main.py` | FastAPI 入口，挂载全部 `/api/*` 路由；启动时预热数据层 |
| `data.py` | 数据层：加载 core/similarity/sentiment/FTS，库外片轻索引（lookup.db），`movie()/all_movies()/core()/fts()` |
| `recommend.py` | 规则推荐 + 意图解析 + 解释卡 `explain_card`；DNA_DIMS = 剧情/演技/情感/视听/节奏 |
| `search.py` | 片名模糊匹配、FTS 短评检索、联想、库外片片名解析 |
| `embed.py` | 文本/影片向量化（512 维），语义检索基础 |
| `build_vectors.py` | 离线构建 `movie_vectors.npz` |
| `chat.py` | AI 对话中枢：意图路由、上下文记忆、推荐/陪看/检索、防幻觉校验、格式治理 |
| `llm.py` | LLM 客户端封装（限流、重试、max_tokens、temperature） |

### 3.2 API 清单
**影片 / 检索**
- `GET /api/movies`：分页列表（region/genre/year/dim 过滤 + 排序 + `q` 搜索）
- `GET /api/movies/{id}`：单片详情（含 dna、sentiment、quotes、similar）
- `GET /api/galaxy`：银河星球坐标与属性（前端 3D 布点）
- `GET /api/search`、`/api/suggest`、`/api/movie-lookup`：搜索 / 联想 / 库外片解析

**AI 对话**
- `POST /api/chat`：统一对话入口（`mode=rec|talk`，携带 device_id / spoiler / 历史）

**人格系统**
- `GET /api/personality/questions`：12 道情境题
- `POST /api/personality/test`：提交答题 → 生成五维 DNA + 关键词画像
- `GET /api/personality/profile`：读取画像
- `GET /api/personality/route`：基于画像的 AI 探索路线

**陪看**
- `GET /api/watch/opening`：AI 陪看开场白（无剧透可选）

**账号 / 个人**
- `POST /api/auth/guest | sms | register | login`：游客/验证码/注册/登录
- `GET /api/account`：个人中心（收藏 + 聊天历史 + 档案完成度）
- `GET /api/explorer`：探索档案（已发现星球 / 徽章 / 探索度）
- `POST/DELETE /api/favorites`：收藏 / 取消收藏

### 3.3 认证与身份
采用 **token 机制**：游客首次访问自动 `auth/guest` 注册并下发 token，存于 `localStorage.cine_token`。前端 `retryOn401` 封装了自愈逻辑——当本地缓存 token 在后端失效（如数据重建）时，自动丢弃旧 token、重新注册游客并重试，避免个人中心/探索档案卡在「未登录」。

## 四、核心功能与实现方式

### 4.1 3D 银河宇宙（`scenes/`）
- `GalaxyScene.tsx`：Three.js Canvas（`@react-three/fiber` + `drei` OrbitControls），含 `StarField`（背景星）、`MapLayer`（点阵地图）、`PlanetLayer`（590 颗星球）。
- `CameraRig`：点击星球 / 聚焦星域时相机平滑推近，清除时拉回全景；`GlobeSpin` 在空闲时整体缓转，交互时暂停防止漂移。
- `EffectComposer + Bloom`：辉光后期，营造星云发光质感。
- 星球按地区分色、评分定亮度；悬停显示信息卡（HUD），点击进入详情并触发「镜头推进」。
- `layout.ts` / `worldmap.ts`：布点算法（斐波那契球面/分区聚焦坐标）。

### 4.2 AI 对话中枢（`chat.py`）
对话入口按 **意图路由** 分四条主线：
1. **电影名解析**：库内优先，库外兜底（`movie-lookup`）。
2. **评论/梗检索**：命中 `_QUOTE_INTENT`（评论/口碑/好评/差评/评分…）才附观众评论卡，**避免无关评论堆叠**。
3. **推荐**：`_answer_recommend`——规则推荐（DNA 顶维/地区/类型）优先，结合历史排重「再推荐几部」。
4. **追问/跟进**：无电影上下文时从历史回溯上一轮推荐片。

**推荐链路的关键治理**（本次迭代重点）：
- **上下文记忆**：`conversation_messages` 记录历史推荐的 `movie_ids`，`_history_seen_ids` 排重，`_rewrite_query` 跳过 chip 话术、回溯原始意图。
- **简介强制完整**：`_enforce_summary` 逐段扫描，记住当前影片，凡含「简介：」或以《片名》开头的段落，一律在「简介：」处截断并接上数据库 `summary` 完整原文，防 LLM 截断/缩写/改写/拆段。
- **格式治理**：`max_tokens` 提升到 2800 防止输出被截；清洗 `**`、`---` 等 Markdown 符号（前端纯文本展示）。
- **卡片与正文对齐**：只保留正文提到的影片卡片；口碑引用只保留最终推荐影片的评论。
- **防幻觉校验**：`_validate_rec_ids`（推荐编号须在候选内）+ `_check_foreign_titles`（库外片名检测），失败则重试或降级离线文案。
- **推荐解释卡**：`recommend.explain_card(m, dna, keywords)` 纯模板生成，防幻觉；有画像给五维契合明细，无画像退化为影片自身数据版。

### 4.3 电影人格测试（第一阶段）
- 12 道情境题 → 计算五维观影 DNA（剧情/演技/情感/视听/节奏）+ 关键词画像，存入 `user_personality`。
- `Personality.tsx` 答题页，`PersonalityCard.tsx` 画像卡（迷你雷达），`MovieRoute.tsx` 基于画像的 AI 探索路线。
- 画像反哺推荐解释（`explain_card` 五维契合）与探索路线。

### 4.4 AI 陪看（第三阶段）
- `Chat.tsx` 支持 `rec`（选片）/ `talk`（陪看）双模式；携电影进入默认 talk + 开场动画（`WatchIntro.tsx`）。
- `watch/opening` 提供无剧透开场；`spoiler` 开关可在个人中心设默认值。

### 4.5 页面与组件（`pages/` + `components/`）
- **页面**：`Detail`（电影空间）、`Explore`（应用式探索：首页/电影库/问影灵/我的）、`List`（电影库筛选）、`Chat`、`Profile`（探索档案）、`Account`（个人中心）、`Personality`、`Login`/`Guest`/`About`。
- **组件**：`HUD`（星图筛选 + 引导）、`Radar`（五维雷达 SVG）、`EChart`、`ExplainCard`（推荐解释，卡内展开）、`Navigator`（AI 导航员）、`MovieRoute`、`PersonalityCard`、`WatchIntro`。
- **场景**：`BootScene`（开场胶片盘蓄力动画）、`GalaxyScene` + `StarField`/`MapLayer`/`PlanetLayer`。
- **路由**：Hash 路由；`AnimatePresence` 采用**并行过渡**（非排队），避免页面切换间隙露出底层背景闪银河。
- **来源记忆**：`sessionStorage` 记录 `cine_route_now` / `cine_detail_from`，详情页返回时回到来源页（探索/人格/电影库）而非一律跳银河。

### 4.6 探索界面日/夜主题
- 顶部按钮切换，仅作用于探索界面；`theme-day` 以 `.theme-day` 作用域覆盖导航、卡片、chip、搜索框、滚动条、「我的」面板等全部组件配色，选择持久化到 `localStorage`。

### 4.7 电影库搜索
- `List.tsx`：地区/类型/年份/评分/DNA 排序筛选 + 分页；`q` 做片名/类型/导演/演员归一化包含匹配。
- **无精确匹配时返回空结果**（不再用规则推荐兜底），前端显示「暂无推荐」，避免「搜什么都有结果」。

## 六、部署与运行

### 环境
- Python（Anaconda）：`D:\anaconda\python.exe`
- 前端：Node + Vite，源码 `cine/web/`，产物 `cine/web/dist/`
- 后端 StaticFiles 实时读盘 `dist/`——**前端改动只需 `npm run build`，无需重启；后端 `.py` 改动必须重启服务**。

### 启动命令
```powershell
# 前端构建
cd cine/web; npm run build

# 后端（端口 8010）
D:\anaconda\python.exe -m uvicorn cine.main:app --port 8010
```

### 重启要点
- FastAPI 不热加载，改 `chat.py`/`main.py` 等后需手动停掉 8010 端口进程再重启。
- Windows PowerShell 不支持 `&&`，用 `;` 分隔。
